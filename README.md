# Liputan Kabar Kota — text-first Blogger theme

## Files

- `template.xml` — complete Blogger XML theme; use this file in Blogger.
- `template-web.xml` — working copy maintained alongside the requested template filename.
- `src/css/critical.css` — small above-the-fold CSS, duplicated into Blogger's `<b:skin>`.
- `src/css/lkk.css` — readable non-critical CSS.
- `src/js/lkk.js` — readable article table-of-contents and featured-image-only article image handling.
- `dist/lkk.min.css` and `dist/lkk.min.js` — production assets generated by `build.sh`.
- Existing legacy assets are retained in the repository but are no longer referenced by the new template.

## Build

Run `sh build.sh` from the repository root. It minifies CSS and JavaScript into `dist/`, reports raw and gzip byte sizes, checks forbidden visual effects, and enforces the critical CSS size limit. The build uses `npx`; no runtime framework is added to the site.

## Blogger setup

1. In Blogger, choose **Tema > Cadangkan** and save a backup before applying anything.
2. Set the Blogger homepage post count to at least 10 so the text headline plus nine distinct list items can render.
3. Upload `src/css/critical.css`, `src/css/lkk.css`, `src/js/lkk.js`, `dist/lkk.min.css`, and `dist/lkk.min.js` to the `main` branch.
4. Preview `template.xml` in Blogger before applying it. Validate the homepage, an article, a label, archive, search, static page, and 404 at mobile and desktop widths.
5. After publishing assets, purge jsDelivr caches:
   - https://purge.jsdelivr.net/gh/liputankabarkota/lkk@refs/heads/main/dist/lkk.min.css
   - https://purge.jsdelivr.net/gh/liputankabarkota/lkk@refs/heads/main/dist/lkk.min.js

CDN URLs used by the template:

- https://cdn.jsdelivr.net/gh/liputankabarkota/lkk@refs/heads/main/dist/lkk.min.css
- https://cdn.jsdelivr.net/gh/liputankabarkota/lkk@refs/heads/main/dist/lkk.min.js

The `main` branch cache is not immutable and updates may not appear immediately. A commit-pinned URL is more stable, but these files intentionally use the requested `refs/heads/main` URLs.

## Rollback

If Blogger preview or the published theme has a problem, return to **Tema > Cadangkan/Pulihkan** and restore the backup made before installation. Do not delete the previous theme assets; this template simply stops referencing them.

## Validation and limitations

The build's byte/gzip output is measured on the machine that runs it. No Lighthouse, field Core Web Vitals, Blogger TTFB, or live visual results are asserted by this repository. Measure a cold-cache mobile Lighthouse run (fast 4G, CPU throttling) and desktop runs on the homepage and article after deployment. Repeat each run five times and report medians.

The article hero remains eager and high-priority, with explicit preload candidates and matching responsive `srcset`/`sizes`. When an article has a featured image, the script removes all images from its body so the featured image is the only article image; a caption on the matching body image is moved to the featured image, and text content remains. If no featured image exists, body images are left intact. The protected NewsArticle schema is unchanged. No Reader Revenue Manager loader was present in the inspected template; the existing CTA placeholder is retained without inventing a third-party script URL.

The homepage has one H1 for the site name; the featured story title is an H2 and includes a small responsive thumbnail. The redundant breaking-news ticker is removed. The logo text and image remain visible on every page, while the H1 wrapper is homepage-only to avoid competing with article/page titles.

The site header uses the supplied 200×200 LKK icon beside the two-line “Liputan Kabar Kota” name. The organization logo URL and dimensions in JSON-LD and article microdata match that image.

Article pages display the PopularPosts widget as a right sidebar from 800px upward and below the article on smaller screens. At 800–1199px, the layout uses a 284px sidebar, 26px column gap, and 10px outer gutters to match the supplied desktop reference. At 1200px and wider, the grid is centered at a maximum width of 1100px with a 320px sidebar and 16px gap. Its Legal Advisor banner uses the full uncropped portrait aspect ratio with lazy-loaded 320px and 640px responsive WebP candidates above a compact, single-column “Liputan Kabar Berita” list. Archive/label page side banners also preserve their full natural proportions and use lazy-loaded 320px/640px WebP `srcset` candidates. On article pages with a featured image, all images in the body are removed, the caption of the matching image is moved to the featured image, and missing featured-image alt/title values are filled from article metadata. Body text remains intact; if there is no featured image, body images remain. The current canonical article URL is excluded from the related-post list.
